Capstone 2025:

Next Step Insight is a web application that significantly reduces the time needed to review possible candidates by filtering people out based on selected criteria. It utilizes a machine learning model to automatically recommend employees who are a good match. Users start by selecting a position that needs to be filled along with selecting any filters to apply to the search. Our software eliminates potential candidates that do not align with the search criteria and highlights those the machine learning model recommends. Our software cuts down on the time that Auto-Owners’ employees spend organizing potential candidate’s details and allows them to spend more time comparing the candidates. This gives Auto-Owners the ability to efficiently fill available roles so they can continue to have a capable and well-staffed team. The front end of our application is built with HTML, CSS and TypeScript in Angular, while the back end is implemented with Spring Boot 3. All the data our application uses is stored in a Microsoft SQL database.
